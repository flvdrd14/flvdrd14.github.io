# Portfólio — Flávio Eduardo

Portfólio de desenvolvimento de jogos, engenharia e modelagem 3D. Site estático feito com HTML, CSS e JavaScript, publicado no GitHub Pages.

## Editar no VS Code

1. Baixe este repositório em **Code → Download ZIP** e extraia a pasta, ou clone com `git clone https://github.com/flvdrd14/flvdrd14.github.io.git`.
2. No VS Code, abra a pasta do projeto.
3. Edite os arquivos abaixo e abra `index.html` no navegador para conferir. Não é necessário instalar dependências ou executar um build.
4. Envie as alterações para a branch `main` para atualizar o site pelo GitHub Pages.

| Arquivo | O que editar |
| --- | --- |
| `index.html` | Sobre mim, trabalhos, formação, experiência, ferramentas e contatos |
| `style.css` | Cores, fontes, espaçamentos e versão para celular; a paleta está em `:root` |
| `app.js` | Textos exibidos ao abrir os detalhes de cada trabalho |
| `assets/CV_Flavio_Assis_PT.pdf` | Currículo para visualizar ou baixar |

Os detalhes dos projetos ainda contêm textos provisórios para preenchimento posterior.

## Publicação

GitHub Pages configurado para a branch `main`, pasta `/ (root)`. O arquivo `.nojekyll` permite servir os arquivos estáticos diretamente.
